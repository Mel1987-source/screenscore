# ScreenScore — v28

Προσωπική εφαρμογή (PWA) για ταινίες και σειρές, με κατάταξη βάσει της βαθμολογίας IMDb.

## Τι νέο έχει η v28
1. **Ημερήσια δεδομένα IMDb.** Κάθε μέρα ένα GitHub Action κατεβάζει τα επίσημα αρχεία βαθμολογιών του IMDb (για προσωπική, μη εμπορική χρήση) και φτιάχνει το `data/imdb-titles.json`. Το Top 100, τα Hidden Gems, η Διάθεση και η Διάρκεια υπολογίζονται τοπικά, σε κλάσματα του δευτερολέπτου, **χωρίς OMDb και χωρίς ημερήσιο όριο**. Η κατάταξη γίνεται πλέον πραγματικά με το IMDb: δεν προηγείται επιλογή από το TMDB.
2. **Σύνδεσμοι.** Φίλτρα, αναζήτηση, ανοιχτός τίτλος και εργαλείο μπαίνουν στη διεύθυνση (π.χ. `?type=tv&sort=votes`, `?title=movie-550`, `?tool=gems`). Το κουμπί «πίσω» του κινητού κλείνει τον τίτλο αντί να βγαίνει από την εφαρμογή. Υπάρχει και κουμπί «Κοινοποίηση».
3. **Ποιότητα χρήσης.** Κάρτες-placeholder κατά τη φόρτωση, περιλήψεις που φορτώνουν μόλις φανεί η κάρτα, ενιαίο σετ εικονιδίων SVG, και προσβασιμότητα (ετικέτες σε όλα τα κουμπιά, ανακοίνωση κατάστασης σε αναγνώστες οθόνης, σύνδεσμος παράκαμψης, ορατό focus, σεβασμός του «λιγότερη κίνηση»).
4. **Εισαγωγή από IMDb / Letterboxd** (εργαλείο «Εισαγωγή»): βαθμολογίες, ό,τι έχεις δει και watchlist από τα αρχεία CSV που εξάγουν.
5. **Οι πλατφόρμες μου:** διαλέγεις στις Ρυθμίσεις τις υπηρεσίες σου (Κύπρος). Ο διακόπτης «Μόνο στις πλατφόρμες μου» δείχνει μόνο ό,τι μπορείς να δεις.
6. **Συγχρονισμός συσκευών** της Watchlist και του προφίλ μέσω του δικού σου Cloudflare Worker.
7. **Κώδικας:** το `app.js` χωρίστηκε σε ενότητες (`js/`), με αυτόματα tests (`npm test`) που τρέχουν σε κάθε αλλαγή πριν από τη δημοσίευση.

Δεν έγινε επιλογή γλώσσας ελληνικά/αγγλικά: για προσωπική χρήση δεν αξίζει να διπλασιαστεί κάθε κείμενο.

## Εγκατάσταση (μία φορά, ~15 λεπτά)

### Α. Φιλοξενία στο GitHub (απαιτείται για τα ημερήσια δεδομένα)
1. Φτιάξε δωρεάν λογαριασμό στο github.com και ένα **νέο repository** (π.χ. `screenscore`). Μπορεί να είναι Private αν έχεις GitHub Pro· αλλιώς Public (τα κλειδιά σου δεν μπαίνουν ποτέ στον κώδικα).
2. Ανέβασε όλα τα αρχεία αυτού του zip (Add file → Upload files), **μαζί με τον φάκελο `.github`**. Αν το πρόγραμμα αποσυμπίεσης κρύβει τους φακέλους που ξεκινούν με τελεία, ενεργοποίησε την εμφάνιση κρυφών αρχείων.
3. Settings → Secrets and variables → Actions → **New repository secret**: όνομα `TMDB_TOKEN`, τιμή το TMDB «API Read Access Token» (το μακρύ `eyJ…`).
4. Settings → Pages → Source: **GitHub Actions**.
5. Actions → «Build data & deploy» → **Run workflow**. Η πρώτη εκτέλεση αντιστοιχίζει δεκάδες χιλιάδες τίτλους με το TMDB και κρατά περίπου 30–60 λεπτά. Οι επόμενες, κάθε πρωί, κρατούν λίγα λεπτά.
6. Η εφαρμογή είναι στο `https://<όνομα-χρήστη>.github.io/screenscore/`. Άνοιξέ την στο κινητό και πρόσθεσέ την στην αρχική οθόνη.

### Β. Cloudflare Worker (προαιρετικό: χωρίς TMDB key στο κινητό, και συγχρονισμός)
1. Δημιούργησε Worker με τον κώδικα του `worker-api.js`.
2. Secrets: `TMDB_TOKEN`, `ALLOWED_ORIGIN` = `https://<όνομα-χρήστη>.github.io`, και για συγχρονισμό `SYNC_TOKEN` (ένας μακρύς τυχαίος κωδικός, π.χ. 30+ χαρακτήρες).
3. Για συγχρονισμό: Storage & Databases → KV → Create namespace, και στο Worker → Settings → Bindings → KV namespace με όνομα μεταβλητής **`SYNC`**.
4. Στην εφαρμογή → Ρυθμίσεις: Worker URL και ο ίδιος κωδικός συγχρονισμού σε κάθε συσκευή.

### Γ. Εισαγωγή του ιστορικού σου
- IMDb: imdb.com → Your ratings → ⋮ → Export (και το ίδιο για τη Watchlist).
- Letterboxd: Settings → Data → Export your data → ανέβασε `ratings.csv`, `watched.csv` ή `watchlist.csv`.

## Πώς δουλεύουν τα δεδομένα
- Περιλαμβάνονται ταινίες και σειρές με **≥1.000 ψήφους και ≥5,0 στο IMDb**. Τα όρια αλλάζουν με τις μεταβλητές `MIN_VOTES` / `MIN_RATING` στο workflow.
- Το κύριο Top 100 απαιτεί ≥10.000 ψήφους IMDb. Τα Hidden Gems χρησιμοποιούν 1.000–75.000, ανάλογα με την επιλογή.
- Η αντιστοίχιση IMDb→TMDB (ελληνικός τίτλος, αφίσα, είδη) αποθηκεύεται στο `data/tmdb-map.json`, ώστε κάθε μέρα να ζητούνται μόνο οι νέοι τίτλοι.
- Η χώρα παραγωγής, το «Δημοφιλέστερα», η αναζήτηση, οι ηθοποιοί και τα «Μόνο στις πλατφόρμες μου» χρησιμοποιούν ζωντανά το TMDB. Οι βαθμολογίες IMDb έρχονται και τότε από τα ημερήσια δεδομένα.
- Χωρίς το αρχείο δεδομένων, η εφαρμογή λειτουργεί όπως η v27 (TMDB + OMDb).

## Για προγραμματιστές
- `js/main.js`: εκκίνηση και συνδέσεις κουμπιών · `core.js`: κατάσταση και βοηθητικά · `tmdb.js`: API · `ratings.js`: βαθμολογία · `imdbData.js`: ημερήσια δεδομένα · `discover.js`: κύρια λίστα · `router.js`: διευθύνσεις · `importer.js`, `sync.js`, `platforms.js` · `tools/*`: εργαλεία.

# ScreenScore PWA — v27: βαθμολογία IMDb

## Τι άλλαξε
- **Η βαθμολογία είναι μόνο του IMDb** (μέσω OMDb). Δεν υπάρχει πια μέσος όρος πηγών.
- **TMDB μόνο ως εφεδρεία**: όταν ένας τίτλος δεν έχει IMDb (ή χωρίς OMDb key / όταν εξαντληθεί το ημερήσιο όριο), εμφανίζεται η βαθμολογία TMDB με σαφή ένδειξη «TMDB». Κατά τα άλλα το TMDB δίνει μόνο πληροφορίες: περιλήψεις, posters, trailer, streaming, λίστες υποψηφίων.
- **Το Trakt αφαιρέθηκε** εντελώς: ρύθμιση, αιτήματα και cache (καθαρίζεται αυτόματα από τη συσκευή). Η πρώτη φόρτωση γίνεται πολύ πιο γρήγορη.
- **Εξομάλυνση με ψήφους IMDb**: prior 7,0/10 και 10.000 ψήφοι IMDb (1.000 για εφεδρεία TMDB).
- **Ελάχιστη βαθμολογία** = ελάχιστη IMDb. Το TMDB προφιλτράρει χαλαρά (1 μονάδα χαμηλότερα) και το ακριβές κόψιμο γίνεται στο IMDb.
- **Hidden Gems**: το «λίγοι θεατές» μετριέται με ψήφους IMDb (Πολύ άγνωστα 1.000–10.000 · Άγνωστα 1.000–30.000 · Λιγότερο γνωστά 1.000–75.000). Κάτω από 1.000 ψήφους IMDb ένας τίτλος αποκλείεται ως ασταθής.
- Η «Ανάλυση αποτελεσμάτων» δείχνει πόσοι τίτλοι δεν έχουν IMDb, αντί για τη σύγκριση πηγών.

## Πώς δουλεύει η επιλογή
Το OMDb δίνει βαθμολογία μόνο για συγκεκριμένο τίτλο, όχι λίστα «καλύτερων», και έχει όριο 1.000 αιτημάτων/ημέρα. Γι' αυτό:
1. Το TMDB φέρνει υποψήφιους με βάση τα φίλτρα σου.
2. Οι 200 πιθανότεροι (100 στις άλλες ταξινομήσεις) παίρνουν βαθμολογία IMDb (cache 30 ημερών).
3. Η τελική κατάταξη γίνεται με το IMDb.

Περιορισμός: ένας τίτλος με χαμηλό TMDB αλλά υψηλό IMDb μπορεί σπάνια να μη φτάσει στη λίστα.

## Σημαντικό
- Για να δουλέψει όπως σχεδιάστηκε χρειάζεται **OMDb API key** (δωρεάν στο omdbapi.com) ή το OMDb μέσω του Worker.
- Το OMDb είναι ανεξάρτητη υπηρεσία, όχι επίσημο API του IMDb.

# ScreenScore PWA — v26

Η v26 είναι έκδοση διορθώσεων και καθαρίσματος. Δεν προσθέτει πολλές νέες λειτουργίες: κάνει τις υπάρχουσες να δουλεύουν σωστά και πιο γρήγορα.

## Διορθώσεις σφαλμάτων
- **Λάθος παράμετρος TMDB**: σε Διάθεση, Βραβεία, Δεκαετία και Ηθοποιό ήταν `vote_count_gte` (αγνοείται από το TMDB) αντί για `vote_count.gte`, με αποτέλεσμα σχεδόν κενές λίστες.
- **Ηθοποιός/σκηνοθέτης**: το `/discover/tv` δεν υποστηρίζει `with_people`, οπότε εμφανίζονταν άσχετες σειρές. Τώρα χρησιμοποιείται η πραγματική φιλμογραφία (`/person/{id}/combined_credits`) και μπορείς να διαλέξεις ανάμεσα σε συνώνυμα πρόσωπα.
- **Cloudflare proxy**: τα εργαλεία και η αρχική φόρτωση ζητούσαν TMDB key ακόμη κι όταν υπήρχε proxy. Διορθώθηκε.
- **worker-api.js**: λάθος URL (`/3//movie`), το `/omdb` απαιτούσε άσκοπα `TMDB_TOKEN`, και το CORS `*` επέτρεπε σε οποιονδήποτε να χρησιμοποιεί τα tokens σου. Τώρα με `ALLOWED_ORIGIN` ο Worker απορρίπτει άλλα sites και δέχεται OMDb μόνο με IMDb ID.
- **Αναζήτηση τίτλου**: πριν έψαχνε μόνο μέσα στους ήδη φορτωμένους τίτλους. Τώρα ψάχνει σε όλο το TMDB.
- **Ταυτόχρονες φορτώσεις**: αν άλλαζες φίλτρο ενώ φόρτωνε, η παλιά φόρτωση μπορούσε να «πατήσει» τη νέα. Τώρα ακυρώνεται.
- **Αποθηκευμένα φίλτρα**: το είδος δεν εφαρμοζόταν σωστά όταν άλλαζε ο τύπος.
- **Smart Discovery / προφίλ**: τα είδη γράφονταν ως ελεύθερο κείμενο στα αγγλικά και δεν ταίριαζαν ποτέ με τα ελληνικά ονόματα. Τώρα επιλέγονται από λίστα.

## Hidden Gems (νέα υλοποίηση)
Ορισμός: υψηλή βαθμολογία, λίγοι θεατές.
- Ζητά από το TMDB απευθείας τίτλους με εύρος ψήφων (π.χ. 300–5.000), ταξινομημένους κατά βαθμολογία. Πριν, έπαιρνε τους *δημοφιλέστερους* και κρατούσε όσους είχαν λίγες ψήφους.
- Εξαιρεί τίτλους των τελευταίων 6 μηνών (λίγες ψήφοι επειδή είναι καινούριοι, όχι επειδή είναι άγνωστοι) και, στις σειρές, ειδήσεις/reality/talk shows.
- Προαιρετικό όριο ψήφων IMDb (π.χ. < 50.000), γιατί το TMDB έχει πολύ μικρότερη βάση χρηστών και «λίγες ψήφοι TMDB» δεν σημαίνει πάντα «άγνωστο».
- Κατάταξη με την εξομαλυμένη βαθμολογία, ώστε ένα 9/10 από λίγους θαυμαστές να μην ξεπερνά αυτόματα ένα σταθερό 8,4.

## Ταχύτητα
- Είδος, γλώσσα, χώρα, περίοδος και ελάχιστη βαθμολογία στέλνονται στο TMDB αντί να φιλτράρονται μετά τη λήψη.
- Η «Καλύτερη αξιολόγηση» σαρώνει έως 20 σελίδες ανά τύπο (πριν 50). Οι άλλες ταξινομήσεις έρχονται έτοιμες από το TMDB (6 σελίδες). Η σάρωση σταματά νωρίτερα όταν το TMDB έχει λιγότερες σελίδες.
- Η cache του Trakt λήγει στις 14 ημέρες και του OMDb στις 30 (πριν δεν έληγε ποτέ). Το Trakt ID κρατιέται, οπότε η ανανέωση κοστίζει ένα αίτημα.
- Ο Worker κρατά τις απαντήσεις TMDB στην cache του Cloudflare για 1 ώρα.

## Βαθμολογία
- Η εξομάλυνση (prior 7,0 / 1.000 ψήφοι) χρησιμοποιεί πλέον τις ψήφους **TMDB**. Με τις ψήφους IMDb (συχνά 100.000+) η διόρθωση πρακτικά εξαφανιζόταν.
- Η προεπιλογή του Top 100 χρησιμοποιεί κι αυτή την εξομάλυνση.
- Νέα ρύθμιση: συμπερίληψη Animation (προεπιλογή: όχι, όπως πριν).

## Απλοποίηση εργαλείων (27 → 18 κουμπιά)
- Αφαιρέθηκαν τα επικαλυπτόμενα: «Top 100 ανά είδος» (= φίλτρο είδους), «Δεκαετία» (οι δεκαετίες 1950–2020 μπήκαν στο φίλτρο Περιόδου), «Smart Discovery Lab» (= Hidden Gems + φίλτρα), «Cloudflare Backend» (οδηγία στις Ρυθμίσεις).
- Συγχωνεύτηκαν: Στατιστικά + Intelligence + Συμφωνία πηγών → «Ανάλυση αποτελεσμάτων». Προφίλ + Ετήσιος απολογισμός. Εξαγωγή + Εισαγωγή → «Αντίγραφο ασφαλείας».
- Ομαδοποίηση σε Ανακάλυψη / Ανάλυση / Προσωπικά.
- Αφαιρέθηκε η ένδειξη «weekly», γιατί τα δεδομένα δεν είναι εβδομαδιαία.

## Άλλες βελτιώσεις
- Λεπτομέρειες: διάρκεια, σεζόν/επεισόδια, σύνδεσμος trailer και αγγλική περιγραφή όταν λείπει η ελληνική.
- «Τι να δω απόψε»: προτιμά τη λίστα «Θέλω να δω» και τα αγαπημένα είδη του προφίλ, και δεν προτείνει ποτέ κάτι που έχεις ήδη δει.
- Προτάσεις: παραλείπουν όσα έχεις ήδη στη Watchlist.
- Η διάρκεια καταγράφεται όταν σημειώνεις «Το είδα», οπότε οι ώρες του απολογισμού είναι πραγματικές (πριν: σταθερά 100 λεπτά).
- Διάθεση: αντιστοίχιση σε είδη TMDB αντί για τυχαίες αγγλικές λέξεις-κλειδιά.
- Το αντίγραφο ασφαλείας περιλαμβάνει και προφίλ και αποθηκευμένα φίλτρα.
- Service worker network-first: μια νέα έκδοση εμφανίζεται στην επόμενη επίσκεψη, χωρίς να «κολλάει» η παλιά.

## Εγκατάσταση
1. Ανέβασε όλα τα αρχεία (εκτός του `worker-api.js`) εκεί που φιλοξενείς την εφαρμογή, αντικαθιστώντας τα παλιά. Τα δεδομένα της συσκευής (Watchlist, κλειδιά, προφίλ) διατηρούνται.
2. Προαιρετικά, κάνε deploy το `worker-api.js` ως **ξεχωριστό** Worker με secrets `TMDB_TOKEN`, `OMDB_KEY` και `ALLOWED_ORIGIN` (η διεύθυνση της εφαρμογής σου, π.χ. `https://screenscore.example.workers.dev`). Μετά βάλε το URL του Worker στις Ρυθμίσεις.

## Γνωστοί περιορισμοί
- Οι πηγές βαθμολογίας έχουν διαφορετικές τάσεις (το Trakt βγάζει συνήθως λίγο υψηλότερα). Ο απλός μέσος όρος δεν το διορθώνει.
- Η πρώτη φόρτωση με Trakt κάνει ακόμη πολλά αιτήματα, μέχρι να γεμίσει η cache. Η ριζική λύση είναι ο Worker να υπολογίζει το Top 100 μία φορά τη μέρα (Cron Trigger + KV).
- Τα «Βραβεία» βασίζονται σε λέξεις-κλειδιά TMDB και είναι ενδείξεις, όχι επίσημο μητρώο.

## Ιστορικό προηγούμενων εκδόσεων
### v20

Η έκδοση v20 βασίζεται στην προηγούμενη λειτουργική v19 και προσθέτει:

1. **Δείκτη αξιοπιστίας ψήφων** (0–100), ως ενδεικτικό δείκτη που αυξάνεται με τον αριθμό ψήφων της ισχυρότερης διαθέσιμης πηγής. Δεν είναι πιθανότητα ούτε βαθμολογία της ταινίας.
2. **Στατιστική εξομάλυνση κατάταξης**: η ορατή τελική βαθμολογία παραμένει ο απλός μέσος όρος των διαθέσιμων TMDB, Trakt και IMDb. Για την ταξινόμηση «Καλύτερη αξιολόγηση» χρησιμοποιείται ξεχωριστή Bayesian-style εξομαλυμένη βαθμολογία με prior 7,0/10 και 1.000 ψήφους.
3. **Φίλτρο περιόδου**: όλες οι χρονιές, τελευταία 5/10 χρόνια ή δεκαετίες 2000–2009, 2010–2019, 2020–σήμερα.
4. **Πρόσθετα φίλτρα**: ελάχιστη βαθμολογία TMDB, χώρα παραγωγής και αρχική γλώσσα.
5. **Εμπλουτισμένη Watchlist**: καταστάσεις «Θέλω να δω», «Το είδα», «Αγαπημένα», φίλτρα κατάστασης/είδους/τελικής βαθμολογίας και αποθήκευση στη συσκευή με localStorage.
6. **Διαφάνεια κατάταξης**: οι λεπτομέρειες κάθε τίτλου δείχνουν τον μέσο όρο, την εξομαλυμένη βαθμολογία κατάταξης και τον ενδεικτικό δείκτη αξιοπιστίας.

## Βασική λειτουργία που διατηρείται
- TMDB scan στις πρώτες 50 σελίδες ανά τύπο, με τουλάχιστον 500 ψήφους TMDB.
- Αποκλεισμός Animation εκτός αν επιλεγεί ρητά το είδος Animation.
- Επιλογή Top 100 με βάση τη συνδυασμένη TMDB + Trakt για τη λειτουργία καλύτερης αξιολόγησης, και κατόπιν τελική κατάταξη με τις διαθέσιμες TMDB + Trakt + IMDb για τους επιλεγμένους 100.
- Διατήρηση των τεσσάρων ταξινομήσεων: Καλύτερη αξιολόγηση, Δημοφιλέστερα, Περισσότερες ψήφοι, Νεότερα.
- IMDb ratings fetched by canonical IMDb ID from TMDB through OMDb, with local cache and daily request counter up to 1,000 requests.
- API keys και watchlist αποθηκεύονται τοπικά στη συσκευή. Δεν αποστέλλονται από την εφαρμογή σε δικό μας server.

## Εγκατάσταση
Ανέβασε τα περιεχόμενα του φακέλου `ScreenScore_PWA` στο ίδιο Cloudflare Worker που χρησιμοποιείς, αντικαθιστώντας τα προηγούμενα αρχεία. Το `sw.js` έχει νέο cache ID για να ανανεωθούν τα αρχεία της εφαρμογής.

## Σημειώσεις
- Η TMDB API key, το Trakt Client ID και το OMDb API key πρέπει να έχουν ρυθμιστεί από τις Ρυθμίσεις.
- Η Watchlist διατηρείται στην ίδια συσκευή/φυλλομετρητή μέσω localStorage. Για χρήση σε άλλη συσκευή χρειάζεται ξεχωριστή ρύθμιση και η λίστα δεν συγχρονίζεται αυτόματα.
- Ο δείκτης αξιοπιστίας είναι ευρετικός, όχι επίσημη μέτρηση TMDB/Trakt/IMDb.
- Η εξομάλυνση είναι σχεδιαστική επιλογή του ScreenScore και δεν αλλάζει τον ορατό μέσο όρο των βαθμολογιών.

## ScreenScore v25 — six major upgrades applied

### 1. Premium Cinematic UI
- Dark cinematic gradient and gold accent palette, improved hero panel, responsive card motion and reduced-motion support.
- Hero backdrop adapts to the first current result when TMDB provides a backdrop image.

### 2. ScreenScore Intelligence
- Result-set insight panel: average combined rating, high-rated count, smaller-vote-sample count, dominant genre, and a short high-score/low-vote discovery list.
- This is deterministic analytics, not an AI-generated verdict or prediction.

### 3. Personal Movie Profile
- Local profile fields (display name, favorite genres, recommendation mood) and watchlist-derived statistics.
- Profile is saved in localStorage; no profile data is sent to a server.

### 4. Advanced Score Engine
- Dedicated explainer and live title example for source average, Bayesian-style ranking score and vote-reliability heuristic.
- Explicit distinction between visible average, ranking score and heuristic reliability.

### 5. Cloudflare Backend Architecture
- Added `worker-api.js`, an optional Cloudflare Worker proxy for TMDB and OMDb, with secrets, CORS, basic per-isolate throttling and cache headers.
- App Settings now accepts a Worker proxy URL. With a configured `/tmdb` proxy and `TMDB_TOKEN` secret, TMDB calls can avoid storing the TMDB key in browser storage.
- Trakt remains a direct client integration. To use OMDb through the proxy, the Worker supports `/omdb`; OMDb UI integration is not automatic yet.
- Deploying the Worker and adding Cloudflare secrets is an account-side step; this ZIP cannot deploy into your Cloudflare account by itself.

### 6. Smart Discovery System
- Smart Discovery Lab filters the current Top 100 by combined rating, TMDB vote count and a profile-preferred genre, plus a random selection action.
- Existing v24 discovery tools are retained.

### Upgrade / deployment
- Upload the contents of `ScreenScore_PWA` to your existing Cloudflare hosting location.
- For the optional proxy, deploy `worker-api.js` separately and set `TMDB_TOKEN` (and optionally `OMDB_KEY`, `ALLOWED_ORIGIN`) as Worker secrets. Then enter the Worker base URL in app Settings.
- v25 service-worker cache ID forces the new app files to refresh.
